🤖 CÓMO CONVERTIR ESTE JUEGO EN UN APK DE ANDROID

Este entorno web genera un archivo HTML5 autocontenido. Para compilar un instalador .apk real para tu móvil Android sin perder ni un píxel ni un sonido, tienes dos vías rápidas:

OPCIÓN 1: CAPACITOR (RECOMENDADA - APK NATIVO COMPLETO)

mkdir mercadona-rage && cd mercadona-rage npm init -y && npm install @capacitor/core @capacitor/cli @capacitor/android npx cap init "Mercadona Rage 89" "com.inserso89.mercadonarage" mkdir -p www && cp mercadona_rage_89.html www/index.html npx cap add android && npx cap open android

Dentro de Android Studio, ve a Build > Build Bundle(s) / APK(s) > Build APK(s) y obtendrás tu archivo app-debug.apk.

OPCIÓN 2: PWABUILDER (RÁPIDA DESDE NAVEGADOR)

Sube este archivo HTML a GitHub Pages, Netlify o Vercel (con HTTPS), abre pwabuilder.com, pega tu URL y selecciona Android para descargar el paquete APK/AAB listo para instalar.
